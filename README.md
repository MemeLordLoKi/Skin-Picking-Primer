# Understanding and Managing Skin Picking: A Personal and Practical Approach

Web version of the document, hosted with GitHub Pages.

- `index.html` is the whole document on one page, with a table of contents, a link for every section and a mobile layout.
- `document.pdf` is the downloadable copy.
- `images/` holds the figures.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Updating

Upload a new `index.html` (or `document.pdf`) over the old one. The site redeploys in about a minute and the address stays the same.

## Linking to a section

Every heading has its own address, for example `.../#trial-4-conclusion`. On a computer, hover over a heading and click `#` to copy its link. On a phone, tap the `#` next to the heading.
